# GitHub

GitHub Report
هو منصة تعتمد على نظام Git لإدارة الإصدارات، وتستخدم لاستضافة المشاريع البرمجية والتعاون بين مطوري البرامج . 

. 
1. ما الفرق بين Git وGitHub؟
git : نظام لإدارة الاصدارات  يعمل على جهاز المستخدم
github : منصة سحابية تستضيف مستودعات git وتتيح التعاون بين المطورين
Repository : هو مستودع يحتوي على ملفات المشروع وسجل التعديلات التي تمت عليه، مما يسهل إدارة المشروع ومشاركته
README.md : هو ملف يستخدم لتوضيح فكرة المشروع، وطريقة استخدامه، ومحتوياته، ويظهر تلقائيًا في الصفحة الرئيسية للمستودع

1. GitHub يستضيف مئات الملايين من المستودعات
يُعد أكبر منصة في العالم لاستضافة المشاريع البرمجية، ويحتوي على مئات الملايين من المستودعات العامة والخاصة.
2.يمكنك العودة إلى أي نسخة سابقة من مشروعك
يحفظ GitHub سجلًا كاملًا لجميع التعديلات (Version History)، مما يسمح باستعادة أي إصدار سابق حتى بعد إجراء تغييرات كثيرة.

4. معظم المشاريع مفتوحة المصدر الشهيرة موجودة على GitHub
مشاريع وتقنيات عالمية مثل Linux وTensorFlow وVS Code وReact تُطوَّر وتُدار عبر GitHub، مما يجعله مركزًا رئيسيًا لتطوير البرمجيات مفتوحة المصدر
